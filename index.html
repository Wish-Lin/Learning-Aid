Surface Code Interactive 2D/3D Visualization
The qubits are located on the edges, which are colored by error type: gray for no error, red for X, blue for Z, and green for both.

The vertex and plaquette excitations appear at the boundary of error paths and are colored in gold.

Manual: Click on edges to add or remove

Random fill errors:
X error: 5%
Z error: 5%


The standard surface-code decoder is Minimum-Weight Perfect Matching (MWPM), which pairs up syndrome defects with the lowest total path cost. This demo uses Edmonds' blossom algorithm to solve it.

This is an interactive torus implemented using Three.js. Zoom and drag to see how the [surface code is implemented]. Note: red = X axis, green = Y axis and blue = Z axis.
